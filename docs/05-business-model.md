## 2. Revenue Model & Pricing

### Subscription tiers (per seat/month, annual billing)
| Tier | Price | For | Key entitlements |
|---|---|---|---|
| **Free** | $0 | Everyone | Public teasers, 5 swipes/day, basic profile, community |
| **Premium** | $49 | Angels/HNWI, founders | Unlimited feed, NL search, 100 AI credits, watchlists |
| **Professional** | $199 | Serious seekers, small advisors | Listing publishing, data room (1 active), readiness coach, analytics |
| **Investor Pro** | $499 | FO/VC principals | Full scores, mandate engine, pipeline CRM, unlimited rooms, priority intros |
| **Fund Manager** | $999 | PE/infra teams | Multi-seat pipeline, IC workflows, portfolio tracking, API read |
| **Enterprise / Investment Bank** | $25k–250k/yr | Banks, corporates, large funds | SSO, white-label rooms, API write, data feeds, dedicated CSM |
| **Government** | $50k–500k/yr | Agencies, SEZs | Country portal, PPP pipeline mgmt, investor analytics, summits |

### Transaction & usage
- Connection/success fees where licensed (0.25–1.0% via partner broker-dealers; introducing-agent fee model elsewhere).
- Featured listings & sponsored placement (auction, strict labeling).
- AI credits beyond quota ($0.10/credit, bulk packs).
- Data & intelligence: market reports ($2–20k), API seats, index licensing.
- Marketplace take rate 10–15% (advisory, legal, valuation, insurance referrals).
- Events/certification: virtual summits, "Nexus Certified Analyst" program.

**Pricing logic challenged:** underpricing institutional buyers is the classic mistake — data/workflow tools anchor against PitchBook ($25k+/seat) and DataSite (per-deal $$$). Nexus prices below incumbents' bundles while capturing more of the workflow.

Sensitivities: paid conversion −1pt ⇒ Y5 revenue −$28M; success-fee regulatory delay ⇒ −$40M Y5 (covered by data/API upside); enterprise sales cycle +6mo ⇒ shift ~$12M Y3→Y4.

## 4. Unit Economics (Y3 targets)
- Blended CAC: $85 (PLG) / $22k (enterprise). LTV: $2.9k (pro seats, 24-mo retention) / $210k enterprise. LTV:CAC > 3 both motions.
- AI cost per active user/mo: <$0.90 (caching, small-model routing for classification; frontier models only for generation).
- Verification cost $4–18/user — charged into onboarding for institutional tiers.
